# Implementation Brief

## Build Objective

Build a production-ready corporate and platform website that establishes Chaorda as the category leader in **Human Understanding Infrastructure** for AI agents.

## Required Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- App Router
- Responsive design
- Server-rendered marketing content
- Client-only interactive proof modules where necessary

## Recommended Routes

```text
/
/technology
/platform
/research
/use-cases
/investors
/company
/contact
```

## Required Global Components

- Site header
- Mobile navigation
- Footer
- Page hero
- CTA group
- Section header
- Proof band
- Architecture diagram
- Code block
- FAQ
- Contact form
- Investor data-room request form

## Required Interactive Components

- Homepage signal-field visual
- Standard agent vs Chaorda-aware agent comparison
- Architecture stack explorer
- SDK language tabs
- Data moat flywheel
- Consent architecture diagram

## Form Requirements

Enterprise access form:

- Name
- Company
- Work email
- Role
- Agent use case
- Estimated interaction volume
- Message

Investor data-room request:

- Full name
- Fund or family office
- Corporate email
- LinkedIn URL
- Check size appetite
- NDA acknowledgement
- Manual approval notice

Research inquiry:

- Name
- Organization
- Email
- Research area
- Message

## Analytics Events

- Hero CTA click
- Architecture CTA click
- SDK tab switch
- Code copy
- Use-case page view
- Investor data-room form start
- Investor data-room form submit
- Enterprise form submit
- Scroll depth to data moat section
- Scroll depth to privacy section

## Non-Negotiables

- Do not position Chaorda primarily as "Emotional Intelligence Infrastructure."
- Do not imply covert emotion tracking.
- Do not use generic chatbot imagery.
- Do not make privacy a footer-only concern.
- Do not bury the infrastructure claim below the fold.
- Do not let the visual system overpower the category message.
