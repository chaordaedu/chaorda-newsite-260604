# Website Architecture

## Architecture Principle

The website should explain one idea fast:

```text
AI agents are becoming capable, but they still fail at the human layer.
Chaorda builds the infrastructure that lets agents understand human state, preference, trust, and context.
```

## Page Roles

| Page | Primary Job | Primary Audience |
| --- | --- | --- |
| Home | Establish the category and route visitors | All |
| Technology | Prove Chaorda is real infrastructure | CTOs, architects, ML engineers |
| Platform | Show how the SDK/runtime is adopted | Product architects, developers |
| Research | Establish technical and ethical credibility | ML researchers, technical recruits, diligence teams |
| Use Cases | Translate infrastructure into enterprise value | Enterprise buyers |
| Investors | Explain venture-scale platform potential | VCs, family offices |
| Company | Make the pivot and mission credible | All |
| Contact | Route inbound demand cleanly | Buyers, investors, researchers |

## Funnel Architecture

### Investor Funnel

```text
Home
→ Investors
→ Technology / Research proof
→ Data room request
```

The investor funnel must answer:

- Is this infrastructure or an app?
- Why is the category large?
- Why now?
- What is the defensible data moat?
- Why can this become a default layer in the agent stack?

### Enterprise Buyer Funnel

```text
Home
→ Use Cases
→ Platform
→ Technology
→ Request access / sandbox
```

The buyer funnel must answer:

- What business problem does this solve?
- How does it improve agent retention, escalation, and trust?
- How does it integrate?
- What data does it collect?
- How is privacy handled?

### Research / Talent Funnel

```text
Home
→ Research
→ Technology
→ Company
→ Contact
```

The research funnel must answer:

- Is the technical problem novel?
- Are the claims precise?
- Is the data collected ethically?
- Is the team serious about human-agent alignment?
