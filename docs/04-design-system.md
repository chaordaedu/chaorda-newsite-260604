# Design System

## Creative Direction

Chaorda should feel like a frontier AI infrastructure company with humanistic restraint. The interface should be quiet, precise, and premium: OpenAI simplicity, Anthropic seriousness, Apple-level interaction polish, and Runway-level proof through motion.

## Principles

- Clarity before spectacle.
- Technical proof before brand abstraction.
- Privacy language integrated into product surfaces.
- Motion used to explain signal behavior, not decorate.
- High contrast, low noise, no generic SaaS blue glow.

## Color Tokens

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#121212` | Primary text, dark surfaces |
| Graphite | `#1D1D1B` | Secondary dark panels |
| Porcelain | `#FDFDFB` | Primary light background |
| Paper | `#F7F5EF` | Warm page background |
| Amethyst | `#4B0082` | Emotional signal accent |
| Amber | `#FFBF00` | Consent, alerts, active states |
| Moss | `#6E7D56` | Research and ethical alignment accents |
| Clay | `#B66B48` | Human warmth, secondary accent |

## Typography

Primary sans-serif:

- Use Inter, Inter Tight, or a licensed equivalent to PP Neue Montreal.
- Tight but readable hierarchy.
- No negative letter spacing.

Editorial serif:

- Use Georgia fallback initially, with Ogg or Untitled Serif if licensed.
- Use sparingly for manifesto lines, research pull quotes, and ethical positioning.

## Layout

- Max content width: 1200-1280px.
- Page gutters: 24px mobile, 40px tablet, 64px desktop.
- Section rhythm: 96-144px desktop, 64-88px mobile.
- Cards: maximum 8px radius.
- Prefer full-width bands and structured grids over nested cards.

## Interaction

- Keyboard-visible focus states on all controls.
- Hover states should be subtle: border contrast, opacity, slight translate of 2px maximum.
- Motion should respect `prefers-reduced-motion`.
- Code blocks include copy buttons and tab controls.
- Forms include inline validation and explicit privacy notice.

## Visual Assets

- Homepage: lightweight WebGL/Three.js emotional ambient mesh.
- Technology: vector-like architecture map rendered in HTML/CSS/SVG or canvas.
- Research: diagrams for consent, dataset flight control, and drift prediction.
- Investors: data flywheel visualization and quantified proof modules.

## Accessibility

- WCAG 2.2 AA target.
- Minimum text contrast: 4.5:1.
- Essential graphical boundaries: 3:1.
- All interactive diagrams require keyboard path and text equivalent.
- Do not rely on color alone to communicate telemetry state.

## Benchmark Alignment

- OpenAI: minimal navigation, restrained page density, calm neutral palette.
- Anthropic: warm academic tone, safety-first copy, high-trust typography.
- Perplexity: clear enterprise utility, security sections, FAQ and conversion clarity.
- Runway: immersive product proof, but Chaorda should keep motion more technical and less cinematic.
